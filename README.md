# Read It! — английские буквы и звуки

**Сайт:** https://konstahasan-cyber.github.io/read-it/ · **Учитель:** https://konstahasan-cyber.github.io/read-it/admin.html

Приложение для ученицы по учебнику «Read It! Phonics Adventure»: алфавит (названия и звуки букв), короткие гласные, 7 уроков буквосочетаний, повторы и финальный тест. Устанавливается на iPhone как приложение, работает без интернета.

- **index.html** — приложение ученицы: уроки по шагам на 5 минут, тренировка, тест, повторение пройденного, словарик, серия дней 🔥, очки, награды.
- **admin.html** — панель учителя: прогресс каждого ученика, ошибки по правилам, история занятий, задания со сроком и статусом («выполнено / ждёт / просрочено»), словарик.

## Как устроено обучение

Каждый урок разбит на шаги по 2 правила: карточки правил → 8 заданий (≈5 минут). После всех шагов — «Повторить весь урок» и тест (нужно 80%, как в учебнике 23/28). Тест открывает следующий урок.

Задания собираются случайно (криптографический генератор). Внутри занятия не повторяются ни пары «правило + тип задания», ни слова; один тип задания не идёт дважды подряд; правильный ответ равномерно распределён по кнопкам и не стоит на одном месте три раза подряд; в неправильных вариантах никогда нет проверяемого правила. Ошибки возвращаются в конце занятия другим типом задания. Повторение пройденного чаще берёт слабые и давно не встречавшиеся правила.

Проверка: откройте `tests/random-check.html` — генератор прогоняет ~20 000 занятий и показывает нарушения (должно быть «Все проверки пройдены»).

## Запуск на компьютере

```
py -m http.server 8765
```
Затем откройте http://localhost:8765. Без сервера (см. ниже) прогресс хранится только на устройстве, а панель учителя показывает ученика на этом же устройстве (демо-режим).

## Обновление сайта

Сайт публикуется через GitHub Pages из этого репозитория. После правок увеличьте `VERSION` в `sw.js`, затем:

```
git add -A
git commit -m "Что изменилось"
git push
```
Через 1–2 минуты изменения появятся на сайте и у учеников.

## Публикация на другом хостинге

Любой статический хостинг с HTTPS. Проще всего — **Netlify Drop**: зайдите на https://app.netlify.com/drop и перетащите папку `read-it`. Получите адрес вида `https://имя.netlify.app`.

После любых изменений файлов увеличьте `VERSION` в `sw.js` (например `readit-v3`), иначе телефоны какое-то время будут показывать старую версию.

## Сервер прогресса (чтобы учитель видел ученицу удалённо)

Бесплатно, ~10 минут:

1. Создайте проект на https://supabase.com.
2. **SQL Editor → New query** → вставьте содержимое `supabase/schema.sql` → **Run**.
3. **Authentication → Users → Add user** — ваша почта и пароль (это вход в панель учителя).
4. **Project Settings → API** — скопируйте *Project URL* и ключ *anon public* в `config.js`.
5. Опубликуйте папку заново.

Дальше в `admin.html`: войдите → «Добавить ученика» → скопируйте ссылку и отправьте ученице. Она открывает её в Safari один раз — приложение запоминает её.

Ключ *anon* можно публиковать: ученик через него может только записывать свой прогресс по своему секретному коду. Читать данные всех учеников может только учитель после входа.

## Установка на iPhone

Safari → открыть ссылку → кнопка «Поделиться» → «На экран „Домой“» → «Добавить». Иконка — плитка «sh». Значок на иконке появляется, если цель дня ещё не выполнена (iOS 16.4+).

## Озвучка через OpenAI (по желанию)

Без неё используется встроенный английский голос телефона — слова он читает нормально, а отдельные звуки (/ʃ/, /θ/) плохо. Скрипт один раз записывает все слова, названия букв и звуки в mp3, ключ остаётся у вас на компьютере:

```
set OPENAI_API_KEY=sk-...
py tools/generate_audio.py
```
Потом увеличьте `VERSION` в `sw.js` и опубликуйте папку вместе с `audio/`.

## Новые темы

1. Положите файл темы в `topics/` (формат как у `phonics.json`: `units` — уроки, `teams` — правила со словами).
2. Добавьте его в `topics/index.json`.
3. Переводы новых слов допишите в `topics/dictionary.json`.
4. Запустите `tests/random-check.html` — он покажет, если для задания не хватает слов или варианты получаются неоднозначными.
